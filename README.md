# 账号用量

一个 DeepSeek Harness 插件：在**右侧边栏**里查看当前登录账号的余额，以及按
**日 / 周 / 月 / 季 / 年** 五个日期维度统计的 **真实 Token 用量与真实消费金额**。

作者：[chaox](https://github.com/lizhichaox) · 仓库：<https://github.com/lizhichaox/dsh-account-usage>

[![verify](https://github.com/lizhichaox/dsh-account-usage/actions/workflows/verify.yml/badge.svg)](https://github.com/lizhichaox/dsh-account-usage/actions/workflows/verify.yml)

## 打开方式

- 快捷键 **⌘U**（macOS 桌面）/ **Ctrl+U**（Windows、Linux 桌面）直接打开面板，并把右侧栏**收到最窄宽度**
  （不用再手动拖窄；宿主没有公开宽度 API，实现是驱动它自己的右栏拖拽手柄，失败时保持当前宽度）；
  该命令已注册到 Harness 快捷键系统，可在「设置 → 通用 → 编辑快捷键」或 **⌘/** 打开的
  「快捷键」对话框里搜索「账号用量」查看与改键（Web 端为避免与浏览器快捷键冲突，默认
  是 ⌘⌥U / Ctrl+Alt+U）
- 或打开右侧边栏，在开始页（Guide）点击 **「账号用量」** 卡片

（左侧栏底部原有的钱包按钮已移除；面板头部只有刷新按钮。）

## 面板内容（顺序：会话消耗 → 用量统计 → 账户余额）

1. **会话消耗**（最上面，按内容高度，不留内部空白）：
   - 大号合计 + Token 构成彩条
   - 输入（未缓存）/输出/缓存读/缓存写 2×2 明细
   - 细分隔线 + **对齐的两列表格**：轮 / 步、请求次数、缓存命中、平均、输出速度、
     模型用时、工具用时、首 Token；标签列定宽、值列左对齐，四行整齐不参差；
     行高 20px、列间距 16px，给文本留出呼吸空间
   - 细分隔线 + 按模型（Provider 作为分组小标题，模型显示短名，最多 3 个）
   - 细分隔线 + 上下文占用、系统/工具/消息构成条；全部单行不换行
2. **用量统计**（中间，默认 `日`；会话全部走第三方 Provider 时隐藏）：`日 / 周 / 月 / 季 / 年` 五个维度切换（日 7 期、周 6 期、
   月 6 期、季 4 期、年 3 期），每期同时显示 **Token 用量** 与 **消费金额**，顶部有区间合计、
   请求次数；当前期淡蓝高亮，行悬停高亮
3. **账户余额**（最下面）：只有充值余额 + 赠送额度，**不显示账号名称、手机号、头像等身份信息**；
   余额和赠送额度改为**左右并排的紧凑布局**（标签在上、金额在下），主金额 24px、赠送额度 18px，
   标签统一 13px 次级色；金额按账号设置页同样的规则格式化（两位小数、千分位、正的不足 1 分显示 `<0.01`）

## 布局与自适应

- 卡片高度：
  - DeepSeek 账号会话：**会话消耗 : 用量统计 = 3 : 4**，账户余额按内容自适应（两列紧凑布局）
  - 第三方 Provider 会话：平台用量卡隐藏，**会话消耗 : Provider 余额卡 = 3 : 2**，
    Provider 卡用大号余额 + 使用率进度条 + 已用/总额明细 + 说明，不再是一张很高的空卡
- **数字层级固定为三级**：
  - `20px / 26px`：会话合计、用量统计合计金额、Provider 主余额
  - `16px / 22px`：账户余额、赠送额度、Provider 已用/总额
  - `13px / 20px`：其余所有明细数字（Token 明细、统计项、每日 Token/金额、按模型、上下文）
  - 全部 `500` 字重、等宽数字（tabular-nums）；超长金额自动降一档字号
- 排版统一：**所有中文文本固定 13px、500 字重**（三张卡标题、标签、维度切换、提示语完全一致），只有数字/金额
  按层级使用不同字号（会话合计 26px、余额 24px、赠送额度 18px、统计合计 17px 等）
- 卡片内**不允许滚动**：用 CSS 容器查询（container query）按卡片高度隐藏次要内容——会话消耗卡先
  隐藏 Token 构成条和按模型块，再隐藏上下文条，最后隐藏 2×2 明细；用量统计卡很矮时隐藏合计行
- Token 数字自动换单位：`K → M → B → T`，某单位超过 999 时自动进位（如 5919M 显示为 5.9B），
  最多保留两位小数（末尾 0 自动去掉，如 `78.77M`、`5.92B`），金额固定两位小数，避免长数字撑破布局
- 右上角刷新按钮（强制重新读取平台数据）+ 自动刷新：余额每 5 分钟、用量每 2 分钟（用量大多命中
  缓存）；页面切到后台时暂停所有自动刷新，回到前台立即补一次
- 载入时统计卡显示逐行骨架屏（而不是一行文字），数据到达后平滑替换
- 维度切换是标准 `tablist`：`←` / `→` / `Home` / `End` 切换，可用键盘完全操作
- 鼠标悬停任意一期，可看到完整「日期 · token · 金额」明细

视觉细节：每张卡标题居中、均为四个中文字符并带小图标（会话消耗 / 用量统计 / 账户余额），标题下方有一条 1px 细分隔线；维度切换是灰底胶囊式分段控件，
选中项白底描边；统计卡条形带渐变；按钮、维度切换与行都有轻微 hover 过渡。
颜色除图表构成条使用少量强调色外，全部来自 `--dsw-alias-*` 主题 token，深浅色自动跟随。

## 设置（右上角齿轮）

面板右上角有**齿轮**按钮，点开标题为「设置」的弹层，改动即时生效（不需要改配置文件，也不需要重启）。
设置保存在浏览器 `localStorage`（键 `dsh.account-usage.settings.v1`），刷新/重开面板后保留：

| 设置项 | 默认 | 作用 |
|---|---|---|
| **默认维度** | 日 | 每次打开面板时初始展示的统计维度（日 / 周 / 月 / 季 / 年） |
| **显示的卡片** | 三张全开 | 分别开关「会话消耗 / 用量统计 / 账户余额」；隐藏的卡片让出高度，其余卡片自动变高 |
| **显示消费金额** | 开 | 关闭后统计卡只显示 Token，不显示每期金额与区间合计金额 |
| **自动刷新** | 开 | 关闭后不再定时请求，只能用右上角刷新按钮手动刷新（用量 2 分钟 / 余额 5 分钟） |
| **隐藏底栏会话统计** | 开 | 隐藏输入框下面那行「轮/步 · tok/s · token · 缓存命中 · 上下文」；相关指标统一显示在会话卡里，可在设置里恢复底栏 |
| **恢复默认** | — | 一键还原以上所有选项（右下角文字按钮） |

弹层布局：标题「设置」+ 右上角关闭 ×；默认维度用一行胶囊；卡片开关、消费金额、自动刷新各占一行，
下方一行小字提示「用量 2 分钟 · 余额 5 分钟」（单行不换行、不省略）；底部右对齐「恢复默认」。
交互细节：齿轮按钮有 `aria-expanded`，弹出层是 `dialog`，点遮罩、按 `Esc`、点 × 都关闭；
开关是 `role="switch"`，键盘可操作。三张卡片全部隐藏时面板显示提示，齿轮仍然可用。

## 浅色 / 深色主题适配

颜色全部来自 DeepSeek Harness 自带 UI 主题，并只使用主题在**浅色和深色下都定义**的 token
（8 个 alias + 4 个 static），没有硬编码颜色、没有 `prefers-color-scheme` 分支、
也没有 `data-ds-dark-theme` 选择器，所以切换主题时自动跟随：

| 用途 | token | 浅色 | 深色 |
|---|---|---|---|
| 卡片底 | `--dsw-alias-bg-layer-1` | `#fff` | `#232324` |
| 卡片边框 / 分隔线 | `--dsw-alias-border-l2` | 10% 黑 | 12% 白 |
| 选中维度边框 | `--dsw-alias-border-l3` | 12% 黑 | 16% 白 |
| 悬停 / 分段底 / 轨道 | `--dsw-alias-interactive-bg-hover`、`--dsw-alias-bg-skeleton` | 半透明填充 | 半透明填充 |
| 主/次文本 | `--dsw-alias-label-primary` / `-secondary` | `#0f1115` / `#61666b` | `#f9fafb` / `#cfd3d6` |
| 构成条 | `--dsw-static-*`（蓝 / 紫 / 琥珀 / 灰蓝） | 与宿主上下文统计条同色系 | 同色系 |

刻意**避开了 `--dsw-alias-bg-layer-2`**：它在浅色主题下与 `bg-layer-1` 同为 `#fff`，
用它做轨道/悬浮底在浅色下会"消失"；改用 `bg-skeleton` 与 `interactive-bg-hover` 这类
半透明填充后，两种主题下都可见。分隔线也从 4% 黑的 `border-l1` 提到 10% 黑的 `border-l2`，
与 Harness 设置页的行分隔线一致。

对比度实测（WCAG，卡片底色上）：

| 内容 | 浅色 | 深色 |
|---|---|---|
| 主文本 / 金额 | **18.9 : 1** | **15.0 : 1** |
| 次要标签 / 时间 | **5.8 : 1** | **10.4 : 1** |
| 错误文字 | **4.5 : 1** | 4.8 : 1 |
| 卡片 vs 侧栏底 | 1.05 : 1（靠 `border-l2` 区分） | 1.10 : 1 |

彩色构成条是装饰性元素（同一数值同时以文字显示），使用与宿主上下文条相同的色系；
其余文字均达到 WCAG AA。

## 数据来源（真实数据）

### 余额

`ctx.remote.account` 的 `getState`（登录态）与 `getBalance`（充值钱包 + 赠送钱包）。

### 按日期的 Token 用量与消费金额

与 DeepSeek 平台「用量」页**同一份数据**：

| 数据 | 平台接口 | 认证 |
|---|---|---|
| 每日 token（缓存命中 / 未命中 / 输出 / 请求数） | `GET {origin}/api/v0/usage/amount?month=M&year=YYYY` | `x-dsh-auth-token: <平台登录态>` |
| 每日消费金额 | `GET {origin}/api/v0/usage/cost?month=M&year=YYYY` | 同上 |

实现方式：

- **Host 半边**（`index.js`）读取 Harness 已登录账号的平台登录态
  （`deepseekAccount.getPlatformSession()`，Host-only，token 不出进程），以
  `x-dsh-auth-token` 头请求上面两个平台接口（这是 Harness 账号服务访问平台接口用的同一套认证），
  按天合并成 `{date, tokens, cost, requests}` 后通过本机回环路由
  `GET /account-usage/platform/usage?year=&month=` 提供给浏览器；Host 侧带 5 分钟缓存与请求去重
- **Client 半边**按当前维度算出需要的月份（日≈1–2 个月、年≈35 个月），并发抓取后按
  本地时区归入日/周/月/季/年桶
- 性能细节：月份并发抓取（6 路）、Host 侧平台登录态缓存 30 秒、Intl 货币格式化器复用、
  过期月份在持久化时自动清理、刷新按钮只重读当前月、后台只预热最宽的「年」窗口（其余维度复用月份缓存）
- 缓存策略：已经结束的月份数据不会再变，浏览器侧缓存 **7 天**（并持久化到 localStorage，
  刷新页面/重启后仍然命中）；当前正在写入的月份缓存 2 分钟；点刷新按钮只强制重新读取**当前月**，
  历史月份直接用缓存，所以刷新不会重新拉 35 个月。首次切到「年」仍需要读约 35 个月，可能要几秒
- **切换维度不闪屏**：每个维度的结果留在内存里，切回已看过的维度会立即渲染（不出现 loading 帧）；
  首次成功加载平台数据后 1.2 秒，后台会静默预取其余维度，因此之后切换基本无等待。
  刷新或后台读取时保留当前图表（不再先清空），数据没有变化时也不触发重渲染；
  切换到从未看过的维度且预取还没完成时，会短暂显示「正在读取用量…」
- 若账号登录态不可用（未登录 / token 失效 / 网络失败），面板会**回退到本地会话记录估算**：
  统计卡标题旁出现「本地估算」小标记，金额带 `≈`
- 统计卡加载时显示「正在读取用量…」（与余额卡的「正在读取…」区分）

> 说明：`/api/v0/usage/*` 是 DeepSeek 平台网页的私有接口（非公开文档 API），
> 与平台「用量」页数据一致但可能随平台改版变化；接口不可用时退化为本地估算（标题旁标记「本地估算」）。

## 零配置，安装即用

- 安装后**不需要填写任何配置项**：没有 API Key、没有 token 输入框、没有设置页。
- 直接复用 Harness 自己已登录的 DeepSeek 账号（右侧栏余额卡用的就是同一个账号）；
  是否登录由 DSH 的账号体系管理，插件不额外要求授权。
- 未登录 / 平台接口不可用时，统计卡自动回退到本地会话估算（带 `≈` 和原因），面板不会空白或报错。
- 桌面与 Web 都可用；快捷键 Desktop 默认 ⌘U / Ctrl+U，Web 默认 ⌘⌥U / Ctrl+Alt+U。
- 不写文件、不启动子进程、不修改 Harness 配置；Host 侧只监听本机回环地址的一个只读路由。

## 隐私与数据

- **读取**：Harness 已登录账号的平台登录态（仅在 Host 进程内使用，不写入日志、不进入模型上下文）、
  账号余额接口、平台用量接口、本机会话的 token 统计（session 列表 + projection）。
  按模型统计由 Host 折叠当前会话的持久日志得到，只返回**模型名称与 Token 数量**，不返回消息内容。
- **发送**：仅向 `platform.deepseek.com` 发送与你账号相关的用量查询请求（与平台「用量」页同源），
  不向任何第三方或自建服务器发送数据；插件没有遥测。
- **缓存**：已结束月份的用量缓存在浏览器 `localStorage`（键 `dsh.account-usage.months.v1`，7 天）
  与插件内存；不缓存凭据。清除方式：删除该 localStorage 键或重装插件。
- **降级**：平台登录态不可用或接口失败时，只使用本机会话记录做本地估算（金额带 `≈`），并显示原因。
- 卸载插件即移除以上全部代码与内存数据；localStorage 缓存可按上面的键手动清理。
- 发布包由 `npm prepack` 自动执行 `scripts/secret-scan.mjs`：扫描所有会被 npm 打包的文件，
  一旦发现密钥、token、邮箱、手机号、本机绝对路径或调试产物就**拒绝打包**。

## 文本可读性

右侧卡片里的文本**不做截断/省略**：长模型名、Provider 名、说明与统计标签会**自动换行**；
金额较长时自动降一档字号（`.aup-value-long` / `.aup-value-longer`），避免超出卡片；
日期标签列按内容宽度自适应。只有极长的模型名会完整换行显示（悬停仍可看到完整原文）。

## 底栏会话统计

DSH 输入框底部原有一行会话统计（轮数/步数 · tok/s · Token · 缓存命中 · 上下文占用）。
本插件启用后（默认，可在右上角设置里关闭「隐藏底栏会话统计」）：

- 通过 `html[data-account-usage-hide-stats] [data-composer-dock]` 隐藏整个底栏统计 dock（同时隐藏 slot 内的统计 pill
  和 slot 外的上下文环形指示器），并用 `[data-composer-stat]` 兜底，避免宿主改结构后残留
- 同样的数据统一在**会话卡**展示，并且**完整覆盖原先底栏 + 「会话统计」弹窗的全部数据**：
  轮数、步数、请求次数、缓存命中、平均每请求、输出速度、模型用时、工具用时、首 token 平均（TTFT）、
  输出 Tokens，以及 Token 合计/明细、上下文占用与系统/工具/消息构成

## 语言

- 跟随 DSH 的语言设置（Settings → General），中文环境显示中文，**其它所有语言一律显示英文**
- 内置语言 `zh` 用中文词典；`en` 用英文；`ja / es / fr / de / ru / pt` 显式注册为英文词典，
  语言包回退链最终到 `en`，因此非中文不会再出现中文文案
- Provider 名称、金额/消费格式、错误原因、时长与单位都随语言切换；切换语言即时生效，无需刷新
- 插件元数据（名称/描述）也提供 `ja/es/fr/de/ru/pt` 的英文回退文件
- 界面文案全部走 `ctx.locale.register('accountUsage', { zh, en, ... })`，不再硬编码中文

## 第三方 Provider 识别与余额

会话不一定走 DeepSeek 账号：DSH 可以配置 OpenRouter、Anthropic、OpenAI、DeepSeek API Key 等
其他 Provider。插件从**当前会话的持久日志**读取每条模型响应的 route，自动区分并切换展示：

| 会话 Provider 情况 | 账户余额卡 | 用量统计卡 | 会话卡 |
|---|---|---|---|
| 全部走 `deepseek-account` | DeepSeek 充值 + 赠送额度 | DeepSeek 平台用量 | 按模型（只写模型名） |
| 全部走第三方（如 OpenRouter） | **变为 Provider 余额卡**：剩余/已用/总额、使用率进度条、说明 | **隐藏平台用量**，改为「会话明细」卡（按模型 + 上下文） | 按模型（Provider 作为分组标题，模型名完整） |
| 混合（部分账号 + 部分第三方） | DeepSeek 余额 + 说明 | DeepSeek 平台 + 说明标记 | 按模型（带 Provider 前缀） |

### Provider 余额支持

| Provider | 查询接口 | 展示 |
|---|---|---|
| `openrouter` | `GET /api/v1/credits`（失败回退 `/api/v1/key`） | 剩余额度、已用（USD） |
| `deepseek` / `deepseek-api`（API Key 路线） | `GET https://api.deepseek.com/user/balance` | 余额、赠送额度（响应币种） |
| 其他 Provider | 无公开余额接口 | 显示「不支持余额查询」说明 |

- 凭据只在 **Host** 侧读取：`ctx.credentials.resolve('OPENROUTER_API_KEY')` 或 `llm-pi-ai/<provider>`
  的存储记录，**API Key 不会返回给浏览器**
- Provider 余额缓存 60 秒；手动刷新会强制重新查询
- 未配置 Key 时显示「未配置 … API Key」，接口失败显示「暂时读不到 … 余额」
- 混合会话仍保留 DeepSeek 余额，并提示「部分使用 …，该部分不消耗 DeepSeek 余额」；
  统计卡显示「DeepSeek 平台」小标记（平台用量只统计账号侧）

## 限制

- 右侧栏只在选中会话时存在，因此面板是会话级的
- 平台「用量」接口是网页私有接口，非官方公开 API；平台改版时可能失效，届时自动回退本地估算
- 平台按 UTC 切分每日数据，面板按平台给出的日期直接分桶（与平台「用量」页日期一致）
